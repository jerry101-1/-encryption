📜 系統更新日誌

⚡ v5.1.0 (UI 介面收納與功能選單升級) 2026/07
  • ⋮ 右上角下拉選單：整合 JSON 匯入/導出、修改密碼、更新日誌，讓主畫面更簡潔清爽。
  • 🔒 快速登出鎖定：於選單新增一鍵登出，清除記憶體金鑰並退回解鎖畫面。
  • 🎨 頂部列排版優化：主題切換與選單按鈕齊右對齊，標題保持置中平衡。
⚡ v5.0.0 (工作台安全與備份大升級) 2026/07
  • 🧹 一鍵銷毀清空：新增銷毀按鈕，一鍵重置輸入框、輸出密文、雙重密碼與解密附件預覽。
  • 🕒 本地歷史暫存區：自動記錄最近 20 筆加解密操作，支援單筆載入與刪除。
  • 📦 JSON 備份與匯入：支援將歷史紀錄完整匯出為 .json 備份檔並跨裝置匯入還原。
🚀 v4.0.0 (全能大版本升級) 2026/07
  • 🌓 深色/淺色主題模式：新增主題切換功能，深色模式採用質感暗色背景與彩色外框按鈕。
  • 📊 字數與容量統計：輸入框新增即時字數統計，輸出框顯示真實 Bytes 與 KB 容量。
  • 📁 檔案與圖片加密：支援上傳圖片/任意檔案轉 Base64 加密，解密自動還原圖片預覽與下載。
🔐 v3.0.0 (加密核心與第二重防護升級) 2026/07
  • 🔒 雙重加密防護 (Second Passphrase)：使用者可自主啟用第二重自訂密碼，達成端到端防護。
  • 🛡️ Web Crypto API 整合：採用 AES-256-GCM 配合 PBKDF2 (100,000 次疊加) 高強度演算法。
  • ⚡ 自動貼上解密：監聽剪貼簿貼上事件，符合 16 進位密文特徵自動執行解密。
👥 v2.0.0 2026/07
  • 🔑 多成員獨立密碼驗證：新增多組成員專屬金鑰，區分不同成員權限與存取狀態。
  • 👁️ 密碼顯示/隱藏切換：輸入框支援點擊眼睛圖示切換明文/密文顯示。
🌱 v1.0.0 (基礎加密筆記本誕生) 2026/06
  • 📝 基礎文字加解密：建立純文字輸入框與輸出框，支援基礎訊息字串加密與解密。
  • 📋 一鍵複製功能：點擊按鈕即可快速將加密結果複製至剪貼簿。
  • 📱 響應式介面設計：建立基礎卡片式 UI 佈局，適應桌機與手機螢幕顯示。
